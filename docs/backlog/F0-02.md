# F0-02 · Git LFS para *.aseprite e art/**/*.png

```text
Porque    Sem LFS o repositório engorda para sempre, e com o eol errado o Git corrompe PNG.
Spec      docs/design/68-o-repositorio-antes-da-primeira-linha-de-jogo.md
Depende   F0-00
Contrato  o "Feito" é o contrato; os números vêm de data/ e da Spec
Feito     git lfs ls-files mostra a arte; addons/ fica de fora; art/source/.gdignore existe
Fora      Meter arte real no repositório — é o ART-01.
Estado    parcial — configurado; a arte que há (art/source/originals, art/export/enramados) está
          fora do LFS de propósito (.gitattributes), e git lfs ls-files não mostra nada
Horas     0,5
```

## Notas

- A C-07 da v5.2: `* text=auto` forçado nos .gitattributes trata os PNG como texto.
- Os placeholders ficam fora do LFS, em art/placeholder/.
- 26/09/2026: o `.gitattributes` põe `art/export/enramados/**` e `art/source/originals/**` como `binary`,
  fora do LFS, pela mesma razão dos placeholders (o CI faz checkout sem LFS). Por isso o "Feito" não se
  cumpre: o `git lfs ls-files` não mostra arte nenhuma. Fecha quando a arte que for para o LFS lá estiver.
